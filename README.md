# 練習用メトロノーム＆レコーダー (Metronome & Recorder)

楽器練習やボイストレーニングにおいて、正確なリズム（メトロノーム）を鳴らしながら演奏音をダイレクトに録音し、その場で聴き返して練習効率を最大化するためのプログレッシブウェブアプリ（PWA）です。

地下スタジオや防音室などの電波が届かない環境でも完全オフラインで動作します。

---

## 主な特徴

1. **高精度メトロノーム (Web Audio API)**
   - `AudioContext.currentTime` をベースにした高精度スケジューリング機構（`lookahead` + `scheduleAheadTime`）。
   - ブラウザのバックグラウンド動作や省電力によるテンポのヨレ・ズレを防止。
   - テンポ（40〜240 BPM）のリアルタイム変更（スライダーおよび ±1 / ±5 微調整ボタン）。
   - 拍子選択（4/4、3/4、2/4、6/8、拍子なし）。
   - 1拍目はアクセント高音（1000Hz）、通常拍は通常音（800Hz）のクリアなクリック音。
   - 音と完全に同期するビジュアルビートインジケーター（1拍目は赤、通常拍は青で発光）。

2. **高音質ダイレクト録音 (MediaRecorder API)**
   - 演奏音のこもりを防ぐため、エコーキャンセル・ノイズ抑制・自動ゲイン調整をオフ（`false`）にしたダイレクト原音キャプチャ。
   - 録音停止後、すぐに画面上のプレイヤーで再生可能。
   - 録音ファイルのローカルダウンロード・保存機能付き。
   - 外部サーバーへの送信は一切行わず、端末内（メモリ/Blob）のみで安全に処理。

3. **完全オフライン対応 (PWA)**
   - Service Worker（Cache-First戦略）による完全ローカル動作。
   - iPhoneのSafariで「ホーム画面に追加」することで、アドレスバーのないフルスクリーンのネイティブアプリとして起動。

## 起動・利用方法

### ローカルでの動作確認（PC / Mac）
Service Workerやマイク機能を使用するため、静的HTTPサーバー（ローカルホスト）経由で起動します。

Python がインストールされている場合：
```bash
# プロジェクトディレクトリで実行
python -m http.server 8000
```
ブラウザで `http://localhost:8000` を開きます。

### iPhone (iOS Safari) での利用・ホーム画面への追加手順

1. 本リポジトリを GitHub Pages や Cloudflare Pages、Vercel 等の無料ホスティング（HTTPS環境）にデプロイするか、同一Wi-Fi内のローカルIPでホストします。
2. iPhone の **Safari** で該当URLを開きます。
3. 画面下部の中央にある **共有ボタン（四角から矢印が出ているアイコン）** をタップします。
4. メニューから **「ホーム画面に追加」** を選択し、右上の「追加」をタップします。
5. ホーム画面に専用アイコンが作成されます。以降は機内モードや電波のない地下スタジオでも、アイコンをタップするだけで即座に起動・利用できます。
